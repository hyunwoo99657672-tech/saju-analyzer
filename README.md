# 천명 — 사주 분석 웹앱

생년월일, 태어난 시간, 성별, 양력/음력을 입력하면 다음 내용을 자동 분석하는 React 웹앱입니다.

- 사주 원국: 년주·월주·일주·시주
- 오행 분포
- 타고난 성격과 기질
- 인간관계
- 연애와 결혼
- 재물운과 직업운
- 건강과 생활 습관
- 대운 흐름
- 삶의 주요 방향
- 결과 인쇄/PDF 저장

## 실행 방법

Node.js 20 이상을 설치한 뒤 프로젝트 폴더에서:

```bash
npm install
npm run dev
```

브라우저에서 터미널에 표시되는 주소를 엽니다.

## 배포

```bash
npm run build
```

생성되는 `dist` 폴더를 Vercel, Netlify, Cloudflare Pages 등에 배포할 수 있습니다.

## 계산 엔진

`manseryeok` 패키지를 사용합니다. 절기 기준 년주·월주, 음양력 변환, 십신, 대운 계산을 지원합니다.

## 다음 확장 권장사항

1. 출생지 선택 및 진태양시 보정
2. OpenAI API를 서버에서 연결해 더 자연스럽고 긴 맞춤 해석 생성
3. 회원가입 및 과거 분석 저장
4. 궁합 분석
5. 결제 후 상세 보고서 PDF 발급
6. 운영자용 해석 문구 관리 화면

## 주의

현재 해석 문장은 오행과 일간을 중심으로 만든 규칙 기반 초안입니다. 사주는 전통 문화적 해석이며 과학적 진단 또는 확정적 미래 예측으로 사용하면 안 됩니다.
